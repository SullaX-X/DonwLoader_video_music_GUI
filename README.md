# 🚀 Media Downloader Pro

**Media Downloader Pro** — это мощное кроссплатформенное приложение с графическим интерфейсом (GUI) для удобного скачивания аудио и видео контента с YouTube, Instagram, TikTok и сотен других площадок. Программа построена на модульной архитектуре, что обеспечивает высокую надежность, читаемость кода и легкость в поддержке.

С любовью разработано **SullaX_X** и **ParsifalX_X**. ✨

---

## ✨ Основные возможности

- **Два режима загрузки:** 🔗 Одиночная ссылка или 📄 пакетная загрузка из `.txt` файла.
- **Поддержка плейлистов:** 📑 Умное скачивание целых каналов и плейлистов в один клик с пропуском уже скачанных файлов.
- **Выбор формата:** 🎵 **Audio (MP3)** 192kbps с обложками или 🎬 **Video (MP4)** в наилучшем качестве.
- 🔐 **Продвинутая авторизация:** Обход защиты Instagram, YouTube 18+ и закрытых площадок через импорт сессий (cookies) напрямую из браузера или внешних файлов.
- 🛠 **Улучшенный UX:** Интерактивный прогресс-бар, **возможность отмены скачивания на лету**, автоматическое открытие папки после загрузки и детальные подсказки при ошибках.
- ⌨️ **Smart Shortcuts:** Полная поддержка `Ctrl+V`, `Ctrl+A` и контекстного меню (правая кнопка мыши) на всех раскладках (вкл. русскую) и на macOS (`Cmd+V`).
- 🏗 **Модульная система:** Код разделен на логические блоки (UI, Core, Utils), что полностью исключает конфликты областей видимости (scope bugs).

## 🛠 Технический стек и ресурсы

Проект построен на базе следующих инструментов с открытым исходным кодом:

- [**yt-dlp**](https://github.com/yt-dlp/yt-dlp) — Основной движок загрузки.
- [**FFmpeg**](https://ffmpeg.org/download.html) — Инструмент для склейки видео и аудио, конвертации форматов.
- [**Pillow**](https://python-pillow.org/) — Библиотека для обработки изображений (необходима для macOS).
- [**Get cookies.txt LOCALLY**](https://chrome.google.com/webstore/detail/get-cookiestxt-locally/ccmclokmbiocneabbicnbaeiocijdhge) — Расширение для безопасного экспорта cookies.

## 👨‍💻 Инструкция для разработчиков (Запуск из исходников)

1. Клонируйте репозиторий.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. **Скачайте статические бинарники FFmpeg и FFprobe** для вашей ОС и положите их в корень проекта (рядом с `main.py`).

   📥 **Официальные ссылки на портативные (static) сборки:**
   - **Windows:** Скачайте `ffmpeg-release-essentials.zip` с сайта [gyan.dev](https://www.gyan.dev/ffmpeg/builds/). Распакуйте папку `bin` и достаньте оттуда `ffmpeg.exe` и `ffprobe.exe`.
   - **macOS:** Скачайте архивы с [evermeet.cx](https://evermeet.cx/ffmpeg/) (Вам нужны оба файла: и ffmpeg, и ffprobe). Распакуйте их (файлы будут без расширения `.exe`).
   - **Linux:** Скачайте `amd64` билд с [johnvansickle.com](https://johnvansickle.com/ffmpeg/). Распакуйте файлы `ffmpeg` и `ffprobe`.

4. На macOS/Linux обязательно выдайте файлам права на исполнение:
   ```bash
   chmod +x ffmpeg ffprobe
   ```
5. Запустите программу:
   ```bash
   python main.py
   ```

## 📦 Сборка в исполняемый файл (Build Guide)

**Важно:** Сборка должна происходить на той ОС, для которой предназначена программа. Внешние инструменты (FFmpeg) вшиваются внутрь файла автоматически.

### 🪟 Windows (.exe)

Убедитесь, что `ffmpeg.exe` и `ffprobe.exe` лежат в папке проекта. Выполните команду:

```bash
pyinstaller --onefile --noconsole -y --icon="app.ico" --add-binary "ffmpeg.exe;." --add-binary "ffprobe.exe;." main.py
```

_Результат: `main.exe` в папке `dist/`._

### 🍏 macOS (.app Bundle) — _Особое внимание!_

macOS имеет строгие правила безопасности и работы с файлами.

1. Установите библиотеку Pillow для обработки `.ico` иконок: `pip install pillow`
2. Убедитесь, что файлы `ffmpeg` и `ffprobe` лежат в папке (строго без расширения `.exe`!) и имеют права `chmod +x`.
3. Соберите приложение (используется флаг `--windowed` для создания нативного `.app`, а разделитель путей — двоеточие `:`):

```bash
pyinstaller --windowed -y --icon="app.ico" --add-binary "ffmpeg:." --add-binary "ffprobe:." main.py
```

_Результат: Полноценное приложение `main.app` в папке `dist/`, готовое к переносу в папку "Программы"._

### 🐧 Linux (Binary)

Убедитесь, что бинарники Linux лежат в папке с правами исполнения. Выполните сборку:

```bash
pyinstaller --onefile --noconsole -y --icon="app.ico" --add-binary "ffmpeg:." --add-binary "ffprobe:." main.py
```

## 💡 Решение частых проблем (Troubleshooting)

- **Ошибка `Unable to find app.ico` (macOS):** На macOS нативные иконки имеют формат `.icns`. Если вы используете `.ico`, убедитесь, что в виртуальном окружении установлена библиотека `Pillow` (`pip install pillow`), иначе PyInstaller упадет с ошибкой.
- **Вопрос `Continue? (y/N)` при сборке:** Означает, что папка `dist` уже существует. Используйте флаг `-y` в команде PyInstaller для автоматической перезаписи.
- **Ошибка `FFmpeg not found` при скачивании:** Вы скачали файлы-пустышки (ярлыки), исходный код (source code) вместо скомпилированных версий (builds), или не выдали им права (`chmod +x` на Mac/Linux). Настоящий FFmpeg весит более 70 МБ.
- **Ошибка авторизации / Блокировка Chrome:** Современные браузеры блокируют свою базу Cookies, пока они открыты. **Решение:** используйте способ с файлом `cookies.txt` (см. ниже).

## 🔒 Скачивание с Instagram / YouTube 18+

Если сервис блокирует загрузку контента без авторизации, используйте систему Cookies:

1. **Файл cookies.txt (Рекомендуется 🏆):** Работает всегда, даже при открытом браузере. Установите расширение **Get cookies.txt LOCALLY** в Chrome/Firefox, авторизуйтесь на сайте, скачайте файл и скормите его программе.
2. **Напрямую из браузера:** Программа попытается сама достать сессию из вашего браузера. ⚠️ **Внимание:** Для этого выбранный браузер (например, Chrome) должен быть **ПОЛНОСТЬЮ ЗАКРЫТ**, иначе ОС не даст программе прочитать базу данных.
